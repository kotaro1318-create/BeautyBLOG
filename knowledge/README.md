# 知識ベースについて

このフォルダには、美容皮膚科学・化粧品科学の専門書籍(非公開の書籍PDF、ユーザーの手元資料)から、
一般読者向けブログ記事のネタ元として使える事実・メカニズム・臨床知見を要約したMarkdownファイルが入っています。

## 著作権に関する方針(重要)

- 元PDFは市販の専門書籍・専門誌であり、公開リポジトリには**含めていません**(このknowledgeフォルダのMarkdown要約のみを収録)。
- 各要約は原文の逐語引用を避け、事実やデータ(著作権の対象外)を執筆者が**自分の言葉で言い換えて**まとめたものです。
- ブログ記事の執筆時にこれらのファイルを参照する場合も、記事本文は必ず独自の表現で書くこと。原文・この要約文をそのままコピー&ペーストしないこと。
- これらの書籍はURLを持たない非公開情報源のため、記事の`sources`フィールドで引用する場合はURLなしで書籍名のみを`{ label: "書籍名(著者)" }`の形で記載する(build.jsはurlなしのsourceを書籍名のみのプレーンテキストとして表示する)。

## 今後の使い方

毎日の記事自動作成エージェントは、新しいトピックを選ぶ際にまずこれらのファイルを読み、
ネタとして使えそうな事実・Q&A・統計を探してから、必要に応じてWebSearchで最新情報(市場動向・海外トレンドなど、書籍がカバーしない領域)を補うこと。
このフォルダは今後、扱う書籍が増えるごとに拡充していく想定(現在8冊/全40冊程度)。
